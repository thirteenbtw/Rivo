# Сервер Rivo на Android-телефоне (тест через Termux)

Это проверка, а не готовое приложение: сервер запускается в Termux как обычная
программа. Интерфейс тот же, что на ПК, открывается в браузере.

## Что нужно

- Android 7+ на 64-битном процессоре (arm64 — почти все телефоны после 2017 г.).
- [Termux](https://f-droid.org/packages/com.termux/) из F-Droid или с GitHub
  (версия из Google Play устарела и не работает).
- Файл `rivo-server-android-arm64` — артефакт сборки CI (job `test`) или из треда.

## Запуск

```sh
pkg update && pkg install ffmpeg          # ffmpeg и ffprobe для перекодирования
termux-setup-storage                      # даст Termux доступ к «Загрузкам»
cp ~/storage/downloads/rivo-server-android-arm64 ~/rivo-server
chmod +x ~/rivo-server
termux-wake-lock                          # чтобы Android не усыплял процесс
~/rivo-server
```

На телефоне откройте `http://127.0.0.1:8096`, на ТВ или ПК — `http://<IP телефона>:8096`
(IP виден в Rivo: Настройки → Сеть, или в настройках Wi-Fi телефона).

Данные лежат в `~/.config/HomeCinema`. Чтобы торренты качались туда, где их видят
другие приложения, в Настройки → Торренты укажите папку `/sdcard/Download/Rivo`.
Папку с фильмами для библиотеки — например `/sdcard/Movies`.

Остановить: `Ctrl+C` в Termux (на клавиатуре Termux есть кнопка CTRL), затем
`termux-wake-unlock`.

## Что проверить

1. Открывается ли интерфейс на телефоне и на ТВ.
2. Каталог и поиск торрентов (нужен интернет, DNS берётся из Termux или 1.1.1.1/8.8.8.8).
3. Скачивание торрента и просмотр «сразу» на ТВ.
4. Перекодирование: файл, который ТВ не играет сам (например HEVC в браузере), —
   насколько быстро идёт и греется ли телефон.
5. Находит ли приложение Android TV сервер само.

## Известные ограничения

- Без `termux-wake-lock` и при агрессивной экономии батареи (Xiaomi, realme, Huawei)
  система может остановить Termux. Отключите для Termux оптимизацию батареи.
- Программное перекодирование 1080p HEVC → H.264 для телефона тяжело.
- iOS не поддерживается: там нельзя держать сервер в фоне.
